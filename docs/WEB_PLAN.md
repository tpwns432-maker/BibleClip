# 웹판 계획 — 함께 읽는 성경 · 작은 커뮤니티

> 2026-11-24 사용자와 합의. 1~5단계(#16~#20) 완료, **2026-11-24 서버 설치 · 운영 중.** 3단계부터 커뮤니티가
> 들어오면서 "함께 노트"를 커뮤니티 글로 합쳤다(아래 "커뮤니티").
> 운영 · 배포 방법 · 그 뒤 바뀐 것 · 남은 일은 **`docs/WEB_OPS.md`**(인수인계 문서).

## 목적
두 사람(나 · 서버 주인)이 **성경을 읽고, 설교를 듣고, 책을 읽고, 느낀 점을 적고 나누는 비공개 공간.**
데스크톱판(설교 준비 · 클립보드 변환 · 자막 발표)과 목적이 다르다. 성경 엔진과 화면(`web/`)은
같이 쓰되, 웹에서는 **기능 구성이 다르고**, 성경 옆에 **커뮤니티**가 있다.

## 합의한 것
- 사용자는 **2명**. 회원가입 없음. 계정은 서버에서 명령으로 만든다.
- **비공개**. 로그인하지 않으면 성경 본문을 포함해 아무것도 보이지 않는다.
- 저작권 역본(개역개정 등)은 **git에 올리지 않는다.** 서버 주인이 서버의 데이터 폴더에 직접 넣는다.
  git에는 지금처럼 코드 + 개역한글 · 원어 자료만 있다.
- 로그인하면 **홈**: 아이콘 두 개 — **성경** · **커뮤니티**.
- 커뮤니티 = 주제별 게시판(글 · 댓글), "공감 ♥" 하나, 글에 "무엇에 대한 감상인지"(설교 · 책) 칸.
- 처음 주제: **말씀 · 모임 서적 · 성경 묵상 · 자유**.
- **함께 노트 = 구절이 달린 커뮤니티 글**(성경 묵상 주제). 나만 노트는 지금 노트 그대로.
- **형광펜은 서로 보인다.**
- 배포: 서버가 **GitHub 저장소**(`tpwns432-maker/BibleClip`, 공개)에서 `git clone` 해서 실행.
  서버 = 리눅스, Docker 없음, 도메인 없음(아래 "배포" · "접속").

## 구조
```
[데스크톱]  화면(web/) ←pywebview→  Python(Api)          한 PC 안 (그대로)
[안드로이드] 화면(web/) ←Bridge.kt→  Kotlin               한 폰 안 (그대로)
[웹]       화면(web/) ←HTTPS→     서버 Python(WebApi)    브라우저 ↔ 서버
           홈 · 커뮤니티(server/static/)
```
- **서버**(`bibleclip/server/`, Flask + waitress): `Api`를 그대로 쓰고 `/api/<기능>`으로 허용 목록만 연다.
- **브라우저**: `server/static/bridge.js`가 `window.pywebview.api.xxx()`를 `fetch`로 바꿔 준다.
  index.html 을 내줄 때 서버가 끼워 넣으므로 `web/`는 고치지 않는다(폰판과 같은 방식).
- **데이터 폴더**(`--data`):
  ```
  users.json            계정(비밀번호는 scrypt 해시만)     secret_key   로그인 쿠키 서명 열쇠
  users/<아이디>/        그 사람의 설정 · 나만 노트 · 형광펜   bible_versions/  역본(서버 주인이 넣음)
  community.db          커뮤니티(주제 · 글 · 댓글 · 공감 · 읽음) — 백업 대상
  ```
- 성경 엔진(역본 · 검색 색인 · 원어)은 서버에 **한 벌**, 사람별 `Library(user_dir, engine)`가 나눠 쓴다.

## 휴대폰 화면
- 휴대폰(손가락 화면 + 짧은 변 600px 미만)으로 성경 화면에 들어오면 **안드로이드 앱의 폰 화면**을 그대로 쓴다:
  서버가 `android/.../assets/android/mobile.css` 를 휴대폰일 때만 켜지게(`media`) 끼우고, bridge.js 가 화면 코드에
  `android` 로 알리고 `mobile.js` 를 불러온다 → 아래 메뉴, 카드 2장 위아래, 병렬 독서 위아래 창.
- 폰의 카드 배치 · 글자 크기는 PC 와 따로(`users/<아이디>/phone_prefs.json`) — 같은 값을 쓰면 폰의 2장 배치가 PC 의
  원어 · 사전 카드를 지운다.
- 앱과 다른 점: **절 메뉴는 절 번호를 눌러** 연다(앱의 2초 누르기는 손가락을 앱이 지켜봐야 해서 브라우저에선 불가 —
  길게 누르면 글자 선택 = 형광펜). 아래 메뉴 맨 앞에 **홈** 단추. 원어 · 사전 카드는 앱처럼 없다.
- 성경 ⚙ 설정 › 웹 › **화면 모양 자동 / 휴대폰 / PC**(이 기기에 기억).

## 테마 (어디서나)
- 성경 ⚙ 설정의 **화면 › 테마**와 같은 값을, 홈 · 커뮤니티 위 막대의 🎨 단추에서도 바꾼다(미리 만든 테마 +
  직접 만들기의 바탕 · 배경 · 글자 · 강조). 같은 저장 기능(`set_app_setting theme · custom_theme`)을 쓴다.

## 성경 ↔ 커뮤니티 (4단계)
web/ 는 고치지 않고 `server/static/bridge.js` 가 그려진 화면(DOM) 위에만 얹는다.
- **함께 쓰기**: 절 우클릭(폰은 길게 누르기) 메뉴 끝에 "함께 쓰기(커뮤니티)". 여러 절을 끌어 고른 채 누르면 그 범위.
  → `community#/new?verse=<책>.<장>.<시작>-<끝>` — 주제는 '성경 묵상'으로 골라지고, 글쓰기 화면에서 절 범위를
  고치거나 뗄 수 있다. 고르는 동안 **읽는 사람의 맨 앞 역본**으로 본문을 미리 보여 준다(`verse_preview`).
- **글 보기**: 제목 아래 "📖 요 3:16-18" + 본문 인용(읽는 사람의 역본). 누르면 성경으로.
- **절 표시**: 글이 걸린 절에 왼쪽 세로줄, 첫 절 끝에 💬(여러 개면 숫자, 새 글이면 점). 누르면 그 글들 + "이 절로 함께 쓰기".
  장마다 한 번 묻고 30초 기억(`verse_posts`). 발표(F11) 중에는 숨긴다.

## 커뮤니티 (3단계)
일반적인 주제별 게시판 형식(Reddit 같은 배치를 참고). 색 · 모양은 BibleClip 테마(사용자 색 테마 포함)를 따른다.
휴대폰 브라우저에서도 쓰기 좋게 한 줄 배치로 줄어든다.

- **주제**: 이름 · 설명 · 기본 감상 종류(말씀 → 설교, 모임 서적 → 책). 두 사람 모두 만들고 이름을 바꿀 수 있다.
  글이 없는 주제만 지울 수 있다.
- **글**: 주제 · 제목 · 본문 · 쓴 사람 · 시간 · 고친 시간. 고치기 · 지우기는 쓴 사람만.
  댓글이 달린 글을 지우면 "지운 글입니다"만 남고 댓글은 유지.
- **무엇에 대한 감상**(선택): 설교 = 제목 · 설교자 · 날짜 · 링크 / 책 = 제목 · 저자 · 읽은 부분.
  글 목록에 칩으로 보이고, 칩을 누르면 **같은 설교 · 같은 책의 글을 모아 본다.**
- **구절**(4단계): 성경 화면에서 고른 구절 범위(한 장 안). 글 위에 "요 3:16-18" 로 보이고 누르면 성경으로.
- **댓글**: 댓글에 댓글을 다는 들여쓰기 대화. 들여쓰기는 4단계에서 멈춘다(그 아래는 같은 폭).
  고치기 · 지우기는 쓴 사람만. 답글이 달린 댓글을 지우면 "지운 댓글입니다".
- **공감 ♥**: 글 · 댓글마다 켜고 끈다. 누가 공감했는지 보인다(두 명이라 이름으로).
- **정렬**: 최근 활동순(새 댓글이 달리면 위로) · 새 글순 · 공감순.
- **새 글 · 새 댓글 표시**: 내가 그 글을 마지막으로 연 뒤에 **상대가** 쓴 글 · 댓글에 "새" 표시.
  홈의 커뮤니티 아이콘과 주제 목록에 개수.
- **구절 자동 링크**: 글 · 댓글 속 "요 3:16", "요한복음 3:16-18", "창1:1" 을 서버가 찾아 링크로
  (데스크톱의 참조 인식기를 그대로 쓴다). 누르면 성경 화면에서 그 구절이 열린다.
- **보안**: 글은 꾸밈 없는 글자로만 그린다(HTML 해석 안 함 → 글 속 코드가 실행될 수 없다). 웹 주소만
  링크로 바꾼다. 길이 제한(제목 200자 · 본문 2만 자 · 댓글 5천 자). 사진 첨부는 1차에 없다.
- **저장**: `community.db`(SQLite, Python 기본 내장). 두 사람이 동시에 써도 안전하고 백업은 파일 복사.
- 화면 글자는 한국어만(두 사람 모두 한국어). 필요하면 나중에 i18n.

## 함께 보는 형광펜 (4단계)
- 저장은 지금처럼 **사람별**. 칠하고 지우는 건 자기 것만.
- 내 형광펜은 지금 모양(배경색), **상대 형광펜은 밑줄**(그 색). 같은 곳을 둘 다 칠해도 둘 다 보인다.
- 그리기는 **CSS Custom Highlight**(문서 구조를 바꾸지 않고 글자 구간에 모양만 입힘)로 한다. 내 형광펜은
  `.vtx` 안에 span 을 넣어 그리고 그 위치로 계산하므로, 상대 것을 같은 방식으로 넣으면 서로 꼬인다 — 이 방식은
  그 코드를 전혀 건드리지 않는다. 지원: Chrome · Edge 105+, Safari 17.2+, Firefox 140+(안 되면 밑줄만 안 보임).
- 누가 칠했는지 말풍선은 없다(두 사람이라 밑줄 = 상대). 성경 ⚙ 설정 › **함께 › 상대 형광펜 보기**로 켜고 끈다
  (이 기기에만 기억).

## 계정 · 보안 (2단계, 완료)
- `python -m bibleclip.server.accounts --data <폴더> add <아이디> --name <이름>` (passwd · remove · list).
- 비밀번호는 scrypt 해시만. 비밀번호를 바꾸면 예전 로그인이 모두 풀린다.
- 로그인 쿠키: HttpOnly · SameSite=Lax · 30일, https 로 접속할 땐 `--secure-cookie`.
- 15분 안에 5번 틀리면 15분 동안 막는다. 다른 사이트에서 보낸 요청(머리글 · Origin · 호스트 검사)은 거절.
- 저장소가 공개라 **비밀 값은 코드에 넣지 않는다**(계정 · 열쇠는 서버의 데이터 폴더에만).

## 배포 (리눅스, Docker 없이 — 5단계)
서버 = 집에 있는 리눅스, Docker 없음 → **Python 가상환경 + systemd**
(systemd = 리눅스가 프로그램을 켜 두고, 꺼지면 다시 켜고, 재부팅 때 자동으로 켜 주는 장치).
서버 주인용 안내서 **`docs/WEB_SETUP.md`**. 서버 주인이 하는 일:
```
sudo git clone https://github.com/tpwns432-maker/BibleClip.git /opt/bibleclip
sudo /opt/bibleclip/deploy/install.sh      # Python · 전용 사용자 · 가상환경 · 서비스 · 계정 · 시작 확인
sudo /opt/bibleclip/deploy/tailscale.sh    # https://<서버>.<사설망>.ts.net 으로 내보내기
sudo /opt/bibleclip/deploy/update.sh       # 업데이트(git pull + 다시 맞춤)
sudo /opt/bibleclip/deploy/backup.sh       # 백업(쓰는 중인 커뮤니티 DB 도 SQLite 백업 기능으로 안전하게)
```
| 위치 | 내용 |
|---|---|
| `/opt/bibleclip` | 프로그램(+ `.venv`). 서비스 사용자는 읽기만 |
| `/var/lib/bibleclip` | 데이터(계정 · 사람별 폴더 · community.db · bible_versions) — 백업 대상 |
| `/etc/bibleclip/web.env` | `BIBLECLIP_PORT` · `BIBLECLIP_ARGS`(tailscale.sh 가 채움) |
- 서비스는 전용 사용자 `bibleclip`(로그인 불가)로, 데이터 폴더 말고는 쓸 수 없게(`ProtectSystem=strict` 등) 돈다.
- 계정은 서버 주인이 만들고, 상대의 비밀번호는 임시로 → 상대가 홈 화면 **"비밀번호 바꾸기"**로 바꾼다
  (바꾸면 다른 기기의 로그인은 풀리고 그 기기는 유지).

## 접속 (도메인 없음)
도메인이 없으면 일반 https 주소(자물쇠)를 받기 어렵다. 후보:

| 방법 | 어떻게 | 장점 | 단점 |
|---|---|---|---|
| **Tailscale**(권장) | 서버와 두 사람 기기에 Tailscale 앱 설치 → 셋만의 사설망. 주소 예: `https://bibleclip.xxx.ts.net` | 인터넷에 아예 안 열림(가장 안전) · 도메인 · 포트 열기 불필요 · https 자동 · 무료 | 접속할 기기(PC · 폰)마다 앱 설치 · 로그인 |
| 무료 주소 + 자동 인증서 | DuckDNS 같은 무료 하위 주소 + Caddy(인증서 자동) | 아무 브라우저로 바로 접속 | 서버를 인터넷에 열어야 함(공유기 포트 열기 · 공인 IP 필요) · 무차별 로그인 시도에 노출 |
| 도메인 사기 | 연 1~2만 원 + Caddy | 깔끔한 주소 | 비용 · 나머지는 위와 같음 |

두 명만 쓰는 비공개 공간이라 **Tailscale**로 정했다(서버 주인 동의). 앱은 127.0.0.1 에만 열고,
`tailscale serve` 가 https 로 받아 넘긴다 → 앱은 `--allow-host <ts.net 주소> --behind-proxy --secure-cookie`
(그 주소를 받아들이고, 접속한 기기 주소 · https 여부는 Tailscale 이 붙여 준 머리글을 믿는다).
상대에게는 관리 화면의 **Share**(기기 하나만 공유)로 연다.
