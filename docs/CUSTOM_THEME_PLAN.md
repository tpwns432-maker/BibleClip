# 사용자 색 테마 계획

> 2026-11-19 사용자 합의. PC·맥·안드로이드 공통(web/ 화면 + Python·Kotlin 설정 저장).
> 피드백: "라이트·다크 말고 색을 직접 바꾸고 싶다"(개인 취향).

## 합의한 범위
- **A + B**: 미리 만든 테마 몇 개 + 기준 색 몇 개를 직접 고르는 "직접 만들기".
  토큰 50개를 하나하나 고치는 편집기(C)는 만들지 않는다.
- **앱 본 창만**. 원어 사전 창·장바구니 창·자막 창·형광펜 색은 이번에 건드리지 않는다.
  사전 창은 지금처럼 바탕(밝음/어두움)만 넘겨받는다.
- **폰에도** 넣는다(web/ 공유, Bridge.kt에 저장 키만 추가).

## 설정 값
| 키 | 값 |
|---|---|
| `theme` | `light` · `dark` · `paper`(종이) · `sage`(숲) · `navy`(남색) · `black`(검정) · `custom` |
| `custom_theme` | `{"base": "light"\|"dark", "bg": "#rrggbb", "text": "#rrggbb", "accent": "#rrggbb"}` |

- `theme`이 없으면(이전 버전 설정) `dark_mode`로 정한다 → 그대로 라이트/다크.
- `theme`을 저장할 때 백엔드가 `dark_mode`도 바탕에 맞춰 같이 쓴다. 이전 버전으로 돌아가도
  밝음/어두움은 유지된다.
- `custom_theme`은 백엔드가 검사한다(base 두 값, 색은 `#` + 16진 6자리). 틀리면 거절.

## 화면 구조
- `<html data-theme>`는 지금처럼 **바탕**(`light`/`dark`)만 뜻한다. 그래서 `[data-theme="dark"]`
  로 쓴 기존 규칙(토글 아이콘·검색 강조·메뉴 그림자)과 사전 창에 넘기는 값이 그대로 맞는다.
- 라이트·다크가 아닌 테마는 `<html data-palette="…">`를 더하고, 기준 색 4개를 인라인 변수로 둔다:
  `--pal-bg` `--pal-text` `--pal-accent` `--pal-on-accent`.
- 나머지 토큰은 `tokens.css`의 `:root[data-palette]` 한 블록이 `color-mix(in oklab, …)`로 계산한다.
  - 카드 = 배경에서 한 단 밝게(어두운 바탕은 아주 조금), 테두리·선 = 글자를 배경에 조금 섞음
  - 흐린 글자 = 글자 65% / 40%, 선택 칩 = 강조 10~15%
  - 강조 글자색: 어두운 바탕에서는 강조를 밝게 섞음(지금 다크 테마와 같은 이유)
  - 왼쪽 레일 = 강조색을 아주 어두운 바탕에 조금 섞음(보라 고정이 다른 강조색과 어긋나므로)
- 미리 만든 테마도 **기준 색 묶음**으로만 정의한다(`web/js/theme.js`). "직접 만들기"는 지금
  고른 테마의 기준 색에서 시작한다.
- `color-mix`를 못 쓰는 WebView면(`CSS.supports`) 테마 목록을 라이트·다크만 보여 준다.

| 테마 | 바탕 | 배경 | 글자 | 강조 |
|---|---|---|---|---|
| 종이 | 밝음 | `#F3EBDC` | `#3A2E22` | `#9B5B2C` |
| 숲 | 밝음 | `#EDF2EC` | `#1F2A22` | `#2E7A52` |
| 남색 | 어두움 | `#0E1729` | `#E3E9F4` | `#5B9BFF` |
| 검정 | 어두움 | `#000000` | `#E6E6E6` | `#8E7CFF` |

## 설정 창
⚙ 설정 맨 위에 **화면** 묶음: 테마 견본 동그라미(라이트·다크·종이·숲·남색·검정·직접).
"직접"을 고르면 아래에 편집 줄이 열린다.
- 바탕: 밝게 / 어둡게
- 배경 · 글자 · 강조: 색 고르기(`<input type="color">`). 고르는 대로 앱 전체가 바로 바뀐다.
- **읽기 어려운 조합 경고**: 글자↔배경 대비 4.5:1 미만, 강조 글자↔배경 3:1 미만이면 경고 문구.
  막지는 않는다(취향 존중).
- 되돌리기: 직접 만든 색을 지금 고른 미리 만든 테마 값으로.

위 레일의 ☀/🌙 버튼은 라이트↔다크만 오간다. 다른 테마에서 누르면 그 테마의 반대 바탕
(밝은 테마 → 다크, 어두운 테마 → 라이트)으로 간다. 직접 만든 색은 지워지지 않는다.
