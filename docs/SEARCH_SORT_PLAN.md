# 검색 결과 정렬 · 필터 계획

> 2026-11-04 사용자 합의. PC·맥·안드로이드 공통(web/ 화면 + Python·Kotlin 검색 엔진).

## 왜 구조부터 바꾸나
지금은 정확도(BM25) 상위 200개만 화면으로 넘어온다("이집트" 655절 중 200절). 이 상태로
성경순·신약만을 하면 "상위 200개 안에서의" 성경순·신약이 되어 틀린다. 그래서

1. 검색은 **걸린 절 전부**(상한 10,000)를 정확도순으로 받는다 — 가장 흔한 "여호와"도
   6,192절 · 0.35초 · 515KB.
2. 정렬·필터는 **화면에서 즉시** 한다(다시 검색하지 않음).
3. 200개씩 그리고 **더 보기**.

엔진(정확도 순서·건수)은 바꾸지 않는다. 받아 오는 개수만 늘린다 — 골든에 전체 결과 케이스를
추가해 데스크톱·폰이 같은 전체 목록을 내는지 확인한다.

## 정렬 (기억함 — 앱 설정 `search_sort`)
| 값 | 이름 | 순서 |
|---|---|---|
| `rank` | 정확도순(기본) | 엔진 순서 그대로 |
| `bible` | 성경순 | 책·장·절 |
| `freq` | 많이 나온 순 | ① 포함한 검색어 수 ↓ ② 검색어가 나온 횟수 ↓ ③ 정확도. 한 단어 검색이면 ①이 모두 같아 "많이 나온 절"부터. 유의어(이집트→애굽)도 센다 |
| `short` | 짧은 구절순 | 글자 수 ↑, 같으면 정확도 |
| `orig` | 원래 단어 먼저 | 검색어가 유의어가 아니라 원래 단어로 나온 개수 ↓, 같으면 정확도 |

세는 법: 검색어 하나 = 그 단어 + 유의어들의 묶음. 본문에서 묶음의 단어(긴 것 우선, 겹치지 않게)
가 나온 횟수를 센다 — 화면의 노란 강조와 같은 규칙. 강조할 단어가 없는 결과(띄어쓰기 없이
붙여 친 구절의 글자 그대로 찾기 등)는 모두 0이라 정확도 순서가 유지된다.

## 필터 (새 검색마다 "전체"로)
범위 하나만 고른다: 전체 · 구약 · 신약 · 묶음 · 책.
- 구약/신약 버튼에 건수.
- 묶음·책 메뉴: 결과가 있는 묶음과 책만, 건수와 함께.
  율법서 · 역사서 · 시가서 · 대선지서 · 소선지서 · 복음서 · 역사(사도행전) · 바울서신 ·
  일반서신 · 예언(요한계시록) · 그 밖(외경 등).
- 분포 막대: 결과 위 66권 막대, 높이 = 건수. 누르면 그 책만, 다시 누르면 전체.

책 번호는 MyBible 번호(창 10 … 말 460, 마 470 … 계 730). 신약 = 470 이상.
