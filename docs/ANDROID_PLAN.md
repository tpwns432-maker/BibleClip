# BibleClip 안드로이드 계획

> 2026-10-31 합의. 작업은 단계마다 Draft PR → 브랜치 → squash 병합.

## 결정 사항
| 항목 | 결정 |
|---|---|
| 화면 | 기존 `web/` 재사용. Kotlin 앱이 WebView로 띄우고, `window.pywebview.api`와 같은 이름의 브리지를 Kotlin이 제공한다 |
| 핵심 로직 | Kotlin으로 이식한다(구절 해석·출력 형식·성경 DB·별칭·검색). 화면 없이 도는 글자 선택 변환(`PROCESS_TEXT`)이 0.1초 안에 응답해야 하기 때문 |
| 최소 버전 | Android 8.0 (API 26) |
| 배포 | 개인 APK 배포(GitHub Release 첨부). Play 스토어는 지금 안 함 |
| 기본 역본 | 데스크톱과 같다 — KRV(개역한글)·KJV+만 동봉, 나머지는 사용자가 추가 |

## 클립보드 감시 대신
- **글자 선택 메뉴**(`ACTION_PROCESS_TEXT`): 어느 앱에서든 "요 3:16" 선택 → BibleClip → 편집 가능한 칸이면 그 자리에서 본문으로 바뀌고, 아니면 클립보드에 복사.
- **공유 받기**(`ACTION_SEND text/plain`), **빠른 설정 타일**, 앱을 열 때 클립보드에 참조가 있으면 배너.

## 단계
| 단계 | 내용 | 끝 기준 |
|---|---|---|
| 0. 시험 제작 | `android/` 골격, Kotlin 엔진·출력 형식, 골든 테스트, WebView+브리지 최소 구현, 글자 선택 변환 | APK 빌드, 골든 테스트 통과, 실기기에서 "요 3:16" 선택 → 본문 |
| 1. 코어 이식 | 성경 DB 전체 API, 별칭 관리, 검색(BM25+유의어), 설정 저장 | 골든 테스트 확장분 통과 |
| 2. 휴대폰 화면 | 리더(절별 역본 세로 쌓기)·변환 화면·설정·역본 관리 | 실기기 주요 흐름, 다크모드, 한/영 |
| 3. 안드로이드 기능 | 공유·타일·클립보드 배너 | 카톡·메모·크롬에서 확인 |

| 5. 테스터 배포 | CI(`android-v*` 태그)로 서명된 APK → Release | 테스터 피드백 반영 |

## 두 벌의 로직을 맞추는 법 — 골든 테스트
`tests/make_golden.py`가 Python 엔진으로 `tests/golden/*.json`(입력 → 기대 출력)을 만든다.
- Python: `tests/test_golden.py`가 JSON이 현재 엔진 출력과 같은지 확인한다(엔진을 고치고 JSON을 안 다시 뽑으면 실패).
- Kotlin: `android/app/src/test`가 같은 JSON을 읽어 비교한다.
엔진을 고칠 때 순서: Python 수정 → `python tests/make_golden.py` → Kotlin이 깨지면 같은 수정 이식.
